# EP-hacks-for-word-list
To use this you have to install tampermonkey.
To use it go onto a Education Perfect word list.
Next copy the words and click the tampermonkey sign.
You should see a line saying paste words.
Click it and paste the words in.
Then you can start.
Each word has a 3 seconds before it starts typing you can change it later.
After you finish or want to stop click the tampermonkey sign and click clear words.
This script reads html so it should not be easily fixed.
